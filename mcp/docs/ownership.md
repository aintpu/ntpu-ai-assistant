# 負責人（Ownership）

規格 12 要求的角色，目前全部由同一人擔任：

| 角色 | 負責人 | 範圍 |
|---|---|---|
| Data owner | 盧信廷 | 來源登記、人工整理檔內容、資料更正 |
| Technical owner | 盧信廷 | 程式、schema、工具契約、ADR |
| Security reviewer | 盧信廷 | 來源 allowlist、工具登記表、權限政策審查 |
| Production operator | 盧信廷 | 部署、監看 `/health`、事故處理與還原 |

公告與介紹頁內容由各處室官網發布；本系統只轉存，不修改原文。法規與常見問答的原始內容由各處室提供，
整理檔由 data owner 維護。

同一人兼任代表審查沒有第二人把關；之後若有協作者，優先把 security reviewer 交給另一個人。
