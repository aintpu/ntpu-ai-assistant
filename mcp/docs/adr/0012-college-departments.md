# ADR-0012：加入商學院所屬四個學系網站

日期：2026-10-14

## 背景
使用者指定加入企業管理學系（www.dba）、金融與合作經營學系（coop）、會計學系（www.acc）、統計學系（www.stat）。
四個網站與商學院（ADR-0010）是同一套 PHP 系統，但各有差異。

## 決定
- 商學院的解析改成共用的 `collegeSite(spec)`／`parseCollegeGroup`，每個網站一組設定（COLLEGE_SITES）。
- 公告：比照商學院補齊歷史公告，以首頁（index.php）上的最新流水號往回列；各網站流水號各自獨立。
  企管系內文頁參數是 `nid`、流水號從 1000001 起編；金融系刊登日期寫在標題右側。內文的「預覽人數」每次瀏覽都會變，不收。
- 會計系最新消息沒有內文頁（全文在列表頁的彈出視窗），再往後的分頁要靠瀏覽器 session：新增 `inline-news` adapter，
  只收 news.php 與四個分類 r_news.php 第二頁上看得到的公告（約 1.5 年），官方連結指向列表頁。
- 內容頁：多個網站的 HTML 標籤沒有正確關閉，DOM 解析會截斷分頁（例如統計系、會計系的師資頁）；改在原始 HTML 上依
  tab-pane 開頭切段。組別取自各網站首頁選單，不收空殼組別，以及金融系、統計系的 page.php?id=1（其實是最新消息列表，
  金融系的含內嵌圖片達 15MB）。
- 附件：各網站附件不在 cms-carrier，MCP 不收附件內容。
- AIA 新增只有 MCP 資料的單位 dba、coop、acc、stat。
