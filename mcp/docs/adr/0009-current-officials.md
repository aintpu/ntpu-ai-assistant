# ADR-0009 — 現任主管結構化資料

Status: Accepted（2026-10-09）

## Context
老師「NTPU AIA 問題與改善建議」二-1：建立現任主管結構化資料，保存姓名、職務、任期、官方來源與最後確認時間；
現任職務問題優先查這份資料，不可從「校長核定」或簽名欄推定。一-1-(2)：人名查詢保留原始姓名，搭配官方中英文別名搜尋。
使用者決定放在 MCP（與其他來源統一、之後好擴充），官網沒有的欄位留空。

## Decision
- 新增來源 `current-officials`（entity_type `official`，adapter `strapi-officials`）：對照表在 `src/ingestion/officials.ts`，
  2026-10-09 人工逐頁核對 18 位主管介紹頁後填寫（校長、三位副校長、一級行政單位主管）。
- 每次抓取用一個固定查詢取得這些頁面（含 `content_en`），確認：
  - 中文姓名仍在中文頁上（國際長官網只有英文姓名，改確認英文姓名）；不在了（換人、改版）→ 記入隔離區，之前那筆不再提供，需要人工重新核對對照表。
  - 官方英文姓名（`nameEnOfficial`，英文頁原文寫法）仍在英文頁上；不在了 → 英文欄留空，不沿用舊值。
- 英文姓名只採用官網英文頁寫明的；英文頁待補、內容是中文、或寫的是前任時留空，不自行以拼音補上。任期只在頁面寫明時才有值。
- 最後確認時間是 provenance.verifiedAt；官方頁面最後修改時間是 `pageUpdatedAt`。
- 新增唯讀工具 `get_current_officials`（R0、L0）：依中英文姓名或職務比對（英文詞序不拘），只回傳分數最高的紀錄
  （「學術副校長」不會連帶列出「校長」）。

## Consequences
- 換人時不會回答舊主管，但要等人工更新對照表才會有新主管的資料；隔離區紀錄與 `/health` 的 quarantinedCount 會提示。
- 對照表目前不含學院院長、系主任、組長；之後擴充只要在 `officials.ts` 加列。
